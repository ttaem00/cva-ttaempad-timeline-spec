컷 작업과 MP4 저장

원하는 장면을 컷 담기로 모은 뒤, 담은 순서대로 확인하고 MP4로 저장합니다. 원본 영상 파일을 따로 준비하지 않아도 다시보기를 출처로 선택할 수 있습니다.

아직 담은 컷이 없으면 다음 행동만 표시됩니다. 컷을 담으면 재생 도구와 목록이 나타나며, 각 컷의 제목 아래에서 출처·시작~끝·길이를 확인할 수 있습니다.

넓은 컷 작업 패널에서는 편집 결과와 저장 카드를 나란히 보고, 아래에서 컷 목록을 조절합니다. 좁은 패널에서는 편집 결과 → 담은 컷 → 저장 순서로 표시됩니다.

시작과 끝 조절하기

  1. 컷 편집에서 출처 영상과 시작·끝을 고르고 컷을 담습니다.
  2. 컷 작업 → 담은 컷에서 수정할 컷을 선택합니다.
  3. 00:00:00 ~ 00:00:00의 시작·끝을 직접 입력하거나 양끝 손잡이를 끕니다.
  4. 경계의 영상을 확인하고 손을 놓으면 변경한 길이를 저장합니다. Esc로 조절을 취소할 수 있습니다.

손잡이에 초점을 두고 방향키로 1초, Shift와 방향키로 10초씩 조절할 수 있습니다. 시작은 끝보다 앞이어야 하며 출처 영상 길이를 넘길 수 없습니다. 컷 목록에는 출처 시각, 결과 재생바에는 담은 컷 전체의 경과시간이 표시됩니다.

결과 확인하기

편집 결과에서 담은 순서대로 재생합니다. 결과의 구간 막대는 각 컷 길이에 비례합니다. 예를 들어 30초 컷과 5분 컷의 막대 길이는 1:10이고, 전체 길이는 5분 30초입니다.

선택한 컷의 제목 아래에는 출처 영상의 시작·끝·길이, 영상 위에는 편집 결과의 재생 시간이 표시됩니다.

목록에서 편집할 컷을 선택하는 동작과 전체 결과를 처음부터 재생하는 동작은 구분됩니다. 선택한 컷은 파란 테두리, 재생 중인 컷은 재생 중 표시로 구분합니다. 다른 컷을 선택해도 현재 재생은 이어집니다. 이 컷 보기는 선택한 컷만, 처음부터 재생은 담은 결과 전체를 재생합니다.

화질과 저장 방법

컷 작업 → 영상·컷 목록 저장에서 MP4 영상의 해상도와 압축을 선택합니다. 녹화 파일을 사용할 때만 내 녹화본 연결을 열면 됩니다.

선택사용 방법
원본·1080p·720p·480p출력 해상도의 상한. 작은 원본을 확대하지 않고 비율을 유지
표준·높은 화질·작은 파일같은 해상도에서 화질과 파일 크기를 조절
일반 다운로드작은 결과를 브라우저 다운로드로 저장. 최대 128 MiB. 큰 결과는 생성 전에 저장 방법을 안내
직접 파일 저장 · 긴 영상에 권장먼저 저장 위치를 고르고 파일에 이어 쓰기. 긴 결과에는 이 방법 권장

저장 방법에서 일반 다운로드 또는 직접 파일 저장을 선택한 뒤 담은 컷 MP4 저장을 누릅니다. 직접 저장은 먼저 저장 위치를 고릅니다. 원본을 덮어쓰지 않도록 새 파일 이름을 선택하세요.

파일 크기는 길이·내용·화질에 따라 달라집니다. 예상 크기가 128 MiB 이상이면 생성 전에 안내합니다. 직접 저장을 선택하거나 화질·컷 길이를 줄일 수 있습니다. 예상 크기와 관계없이 일반 다운로드 진행을 선택해도 실제 128 MiB 제한은 유지됩니다.

0KB로 보일 때

저장 카드에는 준비 → 영상 생성 → 마무리 → 완료가 표시됩니다. 생성 중에는 백분율과 처리한 길이, 생성 데이터 크기를 볼 수 있습니다. 마무리 단계가 끝나야 완료로 표시됩니다.

직접 저장 중 파일이 0KB로 보일 수 있습니다. MP4 저장 완료 뒤 파일을 여세요. 생성 데이터 크기는 디스크에 저장이 끝난 파일 크기와 다를 수 있습니다.

취소하면 MP4 생성 취소 · 완성 파일이 아닙니다가 표시됩니다. 컷 목록은 유지되며 다시 저장할 수 있습니다. 실제 오류는 생성 실패로 구분합니다. 실패했다면 저장 방법이나 화질을 바꾸어 다시 시도하세요.

패널 높이 바꾸기

오른쪽 장면 찾기·장면 상세·컷 편집 패널 아래 손잡이를 끌어 높이를 조절합니다. 방향키로도 조절할 수 있고, Enter 또는 두 번 누르기로 기본 높이로 돌아갑니다. 패널 제목으로 순서를 바꾸는 동작과 아래 손잡이로 높이를 바꾸는 동작은 별개입니다.
