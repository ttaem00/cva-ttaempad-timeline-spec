컷 작업과 MP4 저장

0.4.0 안내: 일반판의 컷 수집·저장과 Pro의 타임라인 편집·자동 저장·전체 편집 공유를 설명합니다. 제품별 Chrome 설치에서 사용할 제품을 고르세요. Store의 실제 공개 버전과 Google 앱 검증 상태는 각각 확인합니다. 출력·재생의 확인 범위와 남은 제한은 문제 해결에 구분합니다.

일반판과 Pro의 새 컷 영역에서 장면을 컷 담기로 모은 뒤, 담은 순서대로 확인하고 MP4로 저장합니다. 원본 영상 파일을 따로 준비하지 않아도 다시보기를 출처로 선택할 수 있습니다.

아직 담은 컷이 없으면 다음 행동만 표시됩니다. 컷을 담으면 재생 도구와 목록이 나타나며, 각 컷의 제목 아래에서 출처·시작~끝·길이를 확인할 수 있습니다.

넓은 컷 작업 패널에서는 편집 결과와 저장 카드를 나란히 보고, 아래에서 컷 목록을 조절합니다. 좁은 패널에서는 편집 결과 → 담은 컷 → 저장 순서로 표시됩니다.

여러 다시보기를 원하는 순서로 담기

일반판과 Pro의 새 컷에서 출처 영상과 시작·끝을 정한 뒤 담을 위치에서 맨 뒤, 맨 앞, 선택한 컷 앞을 고릅니다. 선택한 컷 앞에 넣으려면 먼저 그 컷을 선택하세요.

합방 목록이나 스트리머의 시간축에서 식별된 다시보기를 선택하면, 비교 영상이 아직 로딩 중이어도 그 영상을 새 컷의 출처로 고릅니다. 재생·정지 선택은 늦게 도착한 영상 준비가 뒤집지 않도록 유지합니다. 영상 영역을 선택하거나 컷 출처 버튼으로도 고를 수 있습니다. 작성 중인 새 컷의 시작·끝·이름은 출처별로 보관하므로, 다른 출처를 보고 돌아오면 이전 초안을 이어서 편집할 수 있습니다. 이 초안은 컷 작업을 저장하고 다시 열 때도 보존하며, 이미 담은 컷의 출처·구간은 바뀌지 않습니다.

예를 들어 방송 후반 다시보기를 먼저 담았다면, 앞부분 다시보기를 출처로 고르고 맨 앞으로 담아 전체 순서를 맞출 수 있습니다. 담은 배열 순서가 미리보기·저장·출력 순서입니다. 방송 시각을 보고 자동으로 재정렬하지 않으며, 출처별 원본 시각은 그대로 유지합니다. 실행 취소/다시 실행으로 삽입과 순서를 되돌릴 수 있습니다. 기존 컷 수정은 선택한 원래 자리를 보존합니다.

시작과 끝 조절하기

  1. 새 컷에서 출처 영상과 시작·끝을 고르고 컷을 담습니다.
  2. 컷 작업 → 담은 컷에서 수정할 컷을 선택합니다.
  3. 00:00:00 ~ 00:00:00의 시작·끝을 직접 입력하거나 양끝 손잡이를 끕니다.
  4. 경계의 영상을 확인하고 손을 놓으면 변경한 길이를 저장합니다. Esc로 조절을 취소할 수 있습니다.

장면 목록에서 장면을 먼저 고른 뒤 선택 장면 불러오기를 누르면 새 컷의 시작·끝과 이름을 채웁니다. 이 버튼만으로 컷을 추가하지는 않습니다. 순간 표식처럼 끝이 없는 장면은 끝을 직접 지정한 뒤 컷 담기를 누르세요.

손잡이에 초점을 두고 방향키로 1초, Shift와 방향키로 10초씩 조절할 수 있습니다. 시작은 끝보다 앞이어야 하며 출처 영상 길이를 넘길 수 없습니다. 컷 목록에는 출처 시각, 결과 재생바에는 담은 컷 전체의 경과시간이 표시됩니다.

일반판 개발 후보에는 선택한 다시보기의 길이를 먼저 확인하는 두 버튼이 있습니다.

버튼동작
전체 영상 담기선택한 출처의 0초부터 확인한 끝까지 새 컷으로 담음. 새 컷 담을 위치의 맨 뒤·맨 앞·선택한 컷 앞 적용
영상 끝까지 지정작성 중인 시작은 유지하고 끝만 지정. 시작을 확인한 뒤 컷 담기로 담음

확인하는 동안 관련 편집·출력은 잠기며 확인 취소로 멈출 수 있습니다. 실패하거나 취소하면 기존 초안과 컷을 유지합니다. 출처 전환을 취소했을 때도 기존 출처와 입력을 유지합니다. 전환한 출처에 작성하던 초안이 있으면 복원하고, 처음 고른 출처라면 시작·끝을 정합니다.

버튼으로 선택한 시각은 화면에 표시되는 값보다 정밀할 수 있습니다. 선택한 숫자는 컷 작업을 저장하고 다시 열거나 컷을 수정·나눌 때도 보존하며, 표시 자릿수에 맞춰 끝을 줄이거나 늘리지 않습니다. 시각을 직접 입력해 확정하면 그 입력값을 사용합니다. 같은 표시 값을 다시 확정한 경우도 새 입력으로 취급하며, Esc로 입력을 취소하면 이전의 정밀한 선택을 유지합니다. 가까운 영상 끝이나 키프레임으로 자동 이동시키는 기능은 아닙니다.

설치된 일반판의 메인 Chrome 검사에서 전체 영상 담기 → 정밀 구간을 포함한 컷 작업 JSON 저장 → 실행 취소, 영상 끝까지 지정 → 정밀 초안 JSON 저장을 확인했습니다. 이 확인은 선택·저장 동작의 범위이며, 긴 다시보기 전체의 영상 출력이나 새 전체 소리 복사의 성공을 뜻하지 않습니다.

결과 확인하기

편집 결과에서 담은 순서대로 재생합니다. 결과의 구간 막대는 각 컷 길이에 비례합니다. 예를 들어 30초 컷과 5분 컷의 막대 길이는 1:10이고, 전체 길이는 5분 30초입니다.

선택한 컷의 제목 아래에는 출처 영상의 시작·끝·길이, 영상 위에는 편집 결과의 재생 시간이 표시됩니다.

목록에서 편집할 컷을 선택하는 동작과 전체 결과를 처음부터 재생하는 동작은 구분됩니다. 선택한 컷은 파란 테두리, 재생 중인 컷은 재생 중 표시로 구분합니다. 다른 컷을 선택해도 현재 재생은 이어집니다. 이 컷 보기는 선택한 컷만, 처음부터 재생은 담은 결과 전체를 재생합니다.

화질과 저장 방법

컷 작업 → 영상·컷 목록 저장에서 내보낼 곳을 먼저 고릅니다. 파일로 저장 / YouTube에 업로드 중 하나를 고르면 그 목적지의 방법과 실행 버튼이 표시됩니다. 영상 출처·주소 연결·해상도·압축 품질·원본 복사 선택은 영상 설정에 모여 있으며, 접힌 상태에서도 선택한 출처와 해상도·원본 우선 여부를 볼 수 있습니다. 주소 연결이 필요한 경우에는 설정을 열어 입력합니다. 녹화 파일을 사용할 때만 내 녹화본 연결을 열면 됩니다.

일반판의 MP4 새 작업은 보고 있던 치지직 다시보기, 원본 해상도, 표준 품질로 시작합니다. 작은 기본 표시는 새 작업의 시작값이며 현재 선택과 구분합니다. 이미 저장한 작업의 출처·출력 설정이나 직접 바꾼 선택을 기본값으로 덮어쓰지 않습니다. 원본 유지 · 1080p · 60fps 같은 값과 상세1920×1080은 선택된 내보내기 스트림의 정보이며, 미리보기720p를 대신 표시한 값이 아닙니다. 실제720p·30fps나59.94fps도 그대로 표시하고 알 수 없으면 원본 정보 확인 중 / 프레임률 확인 중으로 남깁니다.1080p 요청과 실제 원본을 구분하며 프레임률을60으로 바꾸거나 추정하지 않습니다. 출력 설정으로 크기가 달라지면 진행 안내에서 출력 치수를 확인하세요. 파일과 YouTube에서 같은 정보를 사용합니다.

일반판의 새 작업은 저장창을 지원하는 브라우저에서 파일에 바로 저장으로 시작하며, YouTube 방법은 Studio 탭 전달이 기본입니다. Pro의 새 Export·Quick Export도 Studio 탭 전달을 기본으로 제안합니다. Google 계정 방식이 안정화될 때까지 이 기본값을 사용하며, 필요하면 빠른 전송(Google 계정)을 직접 고를 수 있습니다. 작은 기본 표시는 새 작업의 시작값을 알리며 선택을 강제하지 않습니다. 저장된 파일 방법과 Pro에서 명시적으로 저장한 Google·Studio 전송 방법은 유지합니다. YouTube에서는 YouTube에 업로드를 누르며, 직접 저장의 위치와 최종 이름은 저장창에서 정합니다. 원본을 보존하려면 새 파일 이름을 선택하세요.

YouTube 실행 버튼 옆 ⓘ 안내를 누르면 두 전송 방식과 Google 로그인·권한 설명을 볼 수 있습니다. 안내는 출력 중에도 읽을 수 있습니다. 빠른 전송에서는 채널 주소나 Studio 탭을 준비할 필요가 없습니다. 작업실의 로그인으로 별도 탬패드 연결 창 없이 Google 공식 로그인·권한 동의 화면을 바로 열고 실제 YouTube 채널을 확인합니다. 채널이 여러 개이면 업로드할 YouTube 채널에서 직접 선택하며, 선택이 없으면 임의로 고르지 않습니다. Studio 로그인만으로 API 업로드 권한이 생기지는 않습니다. 영상을 만드는 동안 Google로 함께 전송해 대기 시간을 줄일 수 있습니다. 환경에 따라 속도는 달라집니다. 선택한 영상과 제목·설명은 Google로 전송되며 모든 영상의 기본 공개 범위는 비공개입니다. 개인정보 처리 안내와 Google 계정 연결 관리를 확인하세요.

파일 크기는 길이·내용·화질에 따라 달라지며, 예상 크기와 완성 파일의 실제 크기는 다를 수 있습니다. 예상 크기가 128 MiB 이상이면 생성 전에 안내합니다. 긴 영상은 파일에 바로 저장을 선택하세요. 일반 다운로드를 이용하려면 화질·컷 길이를 줄일 수 있습니다. 일반 다운로드를 계속하려면 안내에 나타난 예상 크기와 관계없이 일반 다운로드 진행을 선택한 뒤 같은 저장 버튼을 누릅니다. 이 경우에도 실제 128 MiB 제한은 유지되며, 한도를 넘은 출력은 완료로 표시하지 않습니다.

Google 계정 연결과 Studio 탭 선택

일반판의 빠른 전송(Google 계정) 영역과 Pro의 Export·Quick Export에서 같은 계정 조작을 제공합니다. 현재 개발 설치의 일반판과 Pro에서 Google 공식 창이 바로 열리고 계정·채널 선택 뒤 같은 작업실에 연결 채널이 표시되는 흐름을 확인했습니다. Pro는 전송 중 취소 뒤 로그아웃과 재로그인 후 명시적 새 업로드의 비공개 완료도 확인했습니다. 이 관찰은 전체 출시 완료를 뜻하지 않습니다.

파일 전송과 YouTube의 영상 처리는 별도입니다. 비공개 파일 접수 뒤 같은 영상의 처리 상태를 확인하며, 처리 대기·진행 중이거나 조회하지 못하면 재생 준비 완료로 표시하지 않습니다. 처리 실패가 확인되면 이유와 기존 영상 링크를 표시합니다. 처리 대기나 조회 실패만으로 같은 영상을 자동으로 다시 올리지 않습니다. 이후 처리는 Studio에서 확인할 수 있습니다.

빠른 전송은 작은 조각마다 서버 응답을 기다리는 비용을 줄이기 위해 첫 업로드를4MiB 단위로 전송합니다. 실제 서버 수신 시간을 기준으로 다음 업로드부터 조각 크기를 조정하며, 한 편 안에서는 크기를 유지합니다. 최대16MiB의 단일 버퍼를 사용하므로 전체 영상을 메모리에 쌓거나 별도 속도 측정용 영상을 올리지 않습니다. 컴퓨터가 빠르더라도 실제 속도는 원본 읽기·영상 생성·인터넷 업로드 속도의 영향을 받습니다.

YouTube 행동 바로 옆 ⓘ 안내 버튼을 클릭하면 두 전송 방식과 권한 설명을 볼 수 있습니다. 안내는 출력 중에도 열 수 있으며, 안내를 여는 것만으로 출력하거나 문서를 바꾸지 않습니다. 빠른 전송은 선택한 영상과 제목·설명을 Google에 보내며, 영상은 기본으로 비공개 업로드됩니다. 데이터 처리와 권한 안내는 개인정보 처리방침을 확인하세요. 기존 편집자판60초 사례의 생성 중 전송·비공개 저장·같은 파일 디코딩은 한정된 확인이며, 일반판 빠른 전송이나 전체 속도 향상을 보장하지 않습니다. 현재 출력 검증의 한계를 함께 확인하세요.

출력 제어 개발 후보는 일반 Export와 Quick Export에서 진행 중인 작업을 공유합니다. 출력 중에는 새 로컬 내보내기·YouTube 전달·대기열 시작과 재시도, 출력 설정·대상 변경이 비활성화됩니다. 대기열의 취소는 선택한 항목의 대기나 생성을 취소하고, 정지는 현재 생성이 끝난 뒤 다음 항목을 시작하지 않습니다. Quick Export의 닫기는 창만 닫으며 진행 중인 출력을 취소하지 않습니다.

대기 항목의 순서 변경·제거와 종료 항목 정리는 출력 중에도 사용할 수 있습니다. 멈춘 대기열에는 다음 작업을 예약할 수 있습니다. 별도 출력이 진행 중이고 대기열이 실행 상태라면 새 예약은 잠깁니다. 이미 연 프리셋 관리자에서는 목록을 살펴보거나 창을 닫을 수 있지만, 출력이 끝나기 전에는 프리셋을 적용할 수 없습니다. 음량 분석·프록시·미리보기 작업만 실행 중인 경우에는 내보내기를 잠그지 않습니다.

로컬 저장 진행은 준비 → 영상 생성 → 파일 마무리 → 저장 완료로 표시합니다. 영상 생성과 파일 쓰기는 함께 진행됩니다. 영상 생성 백분율과 확인된 누적 저장량을 구분하며, 총크기를 아직 모르면 저장 백분율을 추정하지 않습니다. 영상 생성100%도 저장 완료가 아닙니다. 마지막 파일 닫기와 크기 확인을 끝내야 저장 완료로 표시합니다. 로컬 저장 중에는 YouTube 전달 중으로 표시하지 않습니다.

완료한 MP4 업로드는 작업대에 업로드용 완료 파일이 남아 있을 때만 사용할 수 있습니다. 로컬 직접 저장 결과나 이미 전달 후 정리한 임시 파일은 목록에서 제외됩니다.

일반판과 Pro의 YouTube 진행 표시 개발 후보는 준비 → 영상 생성 → 파일 마무리 → 파일 전달 → 비공개 확인을 구분합니다. Pro의 일반·빠른 내보내기도 같은 단계와 설명을 사용합니다. 영상 생성이 끝나면 MP4 파일 마무리 중으로 바뀌며, 생성100%를 저장·업로드 완료로 표시하지 않습니다. 마무리 게이지는 백분율을 추정하지 않고, Google 전송은 같은 작업에서 확인된 YouTube 수신 바이트를 별도로 보여 줍니다. 수신량이 잠시 늘지 않는 것만으로 마무리가 멈췄다고 단정할 수는 없습니다. 현재 편과 실제 단계를 유지하며, 마지막 파일 닫기와 비공개 접수 확인이 끝나야 해당 완료를 표시합니다.

파일 전달 단계의 100%와 Studio 전달 완료는 비공개 업로드·저장 완료를 뜻하지 않습니다. 비공개 업로드 확인 완료, 고화질 처리와 최종 게시는 각각 구분해 확인하세요. 실패·취소·결과 확인 필요 상태는 멈춘 상태로 표시합니다. 마지막 비율이 남아 있어도 완료나 자동 재시도를 뜻하지 않습니다.

열기와 연결 확인만으로 파일을 생성·전달하거나 업로드하지 않습니다. 선택한 출력 프리셋·범위·원본 유지 설정도 바뀌지 않습니다. 방법과 채널을 확인한 뒤 출력 설정과 범위를 검토하고 YouTube에 업로드를 선택합니다. 이미 준비한 전달의 재시도는 원래 작업을 이어가며, 연결을 열었다는 이유로 같은 파일을 새 탭에 다시 보내지 않습니다. 연결 성공과 실제 업로드·처리 완료는 별도로 확인하세요.
