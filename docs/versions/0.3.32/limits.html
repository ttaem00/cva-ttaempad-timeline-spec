안내별 확인 방법

상황확인할 일
01:23 시작 (02:55)두 순간인지 구간인지 확인. 자동 이동 지점은 앞 시각 01:23
12:99처럼 잘못된 시각초는 00–59. 시각은 MM:SS 또는 H:MM:SS의 정수로 작성
부모 제목 누락## 앞에 해당 # 제목이 있는지 확인
하이라이트 끝 없음시작·끝을 쓰거나 순간으로 바꾸기
끝 미확정댓글 전체를 가져왔는지, 다음 경계·영상 길이를 알 수 있는지 확인
같은 시각·역순 시각별개 항목이므로 원문 설명과 순서 확인
모르는 태그지원 형태와 비교

가장 명확하게 쓰려면

TEXT
# 00:00 ~ 10:00 첫 게임
## 01:00 ~ 05:00 첫 판
- 02:35 다시 볼 순간
- 03:00 ~ 03:20 [H?] 검토할 장면
  • 시각은 줄 앞에 쓰고 설명을 붙입니다.
  • 여러 순간은 /, 범위는 ~로 구분합니다.
  • 별도 곡 목록·색인은 단독 ■나 구분선 뒤에 둡니다.
  • 가져온 뒤 미리보기에서 구조와 원문을 확인합니다.

자동으로 확정하지 않는 것

입력주의할 점
날짜·URL·댓글 ID·자유문장의 숫자모두 영상 시각으로 바꾸지 않음
괄호 안 시각이동 지점·종료·정정 중 무엇인지 직접 확인
자유 제목·들여쓰기구조 근거가 없으면 주제 구간으로 만들지 않음
인물 이름자동 검색한 방송인이 맞는지 목록에서 확인. 겹치는 다시보기를 불러온 뒤 어긋난 장면은 시각 보정

전각 숫자, 임의 분류, 복잡한 Markdown·HTML의 모든 변형은 지원하지 않습니다. 댓글 자동 게시, 답글 전체 자동 수집, 이미 채택한 자료의 자동 변경도 하지 않습니다.
