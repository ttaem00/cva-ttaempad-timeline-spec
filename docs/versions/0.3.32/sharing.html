0.3.32 · 이전 기록 — 보존된 당시 안내입니다. 버전 기록

링크로 시간표 공유하기

댓글이 없는 다시보기에도 시간표와 합방 정보를 붙여 볼 수 있습니다. 상단 자료 불러오기 옆의 공유 링크로 내보내기에서 링크를 만들고, 탬패드가 설치된 Chrome에서 열면 같은 다시보기의 공유 작업실이 열립니다.

보내는 사람

  1. 원하는 댓글·요약을 시간축에 불러옵니다.
  2. 공유 링크로 내보내기를 눌러 이름과 담을 정보를 고릅니다.
  3. 링크 복사를 눌러 전달합니다.

집계나 컷을 함께 보내려면 채팅량·클립 집계, 컷·녹화본 연결 정보를 선택하세요. 입력 중인 원문은 별도 선택 항목입니다.

짧은 주소로 보내기

단축 URL로 내보내기 (s.ttaem.com)를 체크하고 링크 복사를 누르면 https://s.ttaem.com/… 형태로 전달할 수 있습니다. 받는 사람은 이 주소를 열면 원래 다시보기의 공유 작업실로 이동합니다.

체크하지 않으면 원래 긴 링크를 복사합니다. 단축 주소는 만든 시점부터 7일간 열 수 있습니다. 기간이 지나면 보낸 사람에게 새 링크를 요청하세요. 원래 긴 링크와 JSON 파일에는 이 단축 주소의 만료가 적용되지 않습니다.

단축을 선택하면 원래 링크와 생성·만료 시각을 서버 DB에 기록합니다. 만료 후에도 단축 기록은 보관하며, 전체 목록은 공개하지 않습니다. 주소를 아는 사람은 포함된 자료를 열 수 있습니다. 영상 파일은 전송하지 않습니다.

이미 만든 긴 링크는 s.ttaem.com에 붙여 넣어 줄일 수도 있습니다. 생성에 실패하면 원래 링크를 사용하세요.

아래의 예제 링크를 복사해 s.ttaem.com에서 직접 짧은 주소를 만들 수 있습니다.

받는 사람

공유 링크를 열면 상단에 공유 자료 · 이 탭에서 편집이 표시됩니다. 기존에 저장한 댓글·컷을 덮어쓰지 않고 볼 수 있습니다. 영상은 자동으로 함께 재생하지 않습니다.

이미 작업실을 열고 있었다면 공유 내용이 먼저 안내됩니다. 입력 중인 원문을 파일로 보관한 뒤 이 자료로 작업실 열기를 누르세요.

이 브라우저에 별도로 저장을 누르면 해당 영상의 마지막 공유 작업을 보관합니다. 다음에는 공유 링크로 내보내기 → 공유 자료 열기 → 저장한 공유 열기로 이어 볼 수 있습니다. 전체 설정의 데이터 관리에서도 백업·삭제할 수 있습니다.

링크가 너무 길다면

선택한 정보를 빼지 않고 공유 JSON 저장으로 전달하세요. 받는 사람은 해당 다시보기의 공유 링크로 내보내기 → 공유 자료 열기에서 JSON 파일을 선택합니다. 파일만 골랐을 때는 현재 작업이 바뀌지 않습니다.

공개 주소를 사용하는 방법도 있습니다. 공유 JSON을 ttaem.com 또는 이 공개 가이드의 HTTPS JSON 주소에 올린 뒤 큰 자료를 공개 JSON 주소로 공유에 주소를 넣습니다. 로그인 없이 읽을 수 있는 파일이어야 합니다. 공유 메뉴가 파일을 자동 업로드하지는 않습니다.

원래 링크는 8,192자까지, 공유 JSON은 16 MiB까지 지원합니다. 브라우저에 별도 저장할 자료는 8 MiB 이하입니다. 단축 주소로 바꿔도 원래 링크의 용량 제한은 같습니다. 큰 집계·컷 작업은 JSON 파일이나 공개 JSON 주소로 전달하세요. 공개 JSON 주소로 만든 링크도 단축할 수 있습니다.
