이용 정책

다시보기 시청과 일반 키리누키·영상 편집에 사용할 수 있습니다. 수익화 채널의 영상 제작도 허용합니다.

하고 싶은 일이용 조건
개인적으로 다시보기 탐색·비교·컷 편집사용 가능
일반 키리누키·편집 영상 제작과 게시수익화 채널도 사용 가능
프로그램 수정 후 개인적으로 사용사용 가능
프로그램·수정본을 별도 앱이나 설치 파일로 배포무료 배포도 사전 서면 허가 필요
프로그램을 판매하거나 유료 소프트웨어·편집 서비스로 제공사전 서면 허가 필요

영상과 출처

방송 영상·음원·이미지의 이용은 해당 방송인과 플랫폼의 규칙을 따릅니다. 탬패드 이용 허가가 영상의 재사용 허가를 대신하지 않습니다.

기존 TTaem CVA 로고와 ttaem.com 링크가 들어 있는 HTML 요약을 공유할 때는 그 표기를 유지해 주세요. 내보낸 MP4나 컷 목록에 로고·워터마크를 추가할 의무는 없습니다.
