작성 기준

시각을 쓰고, 설명을 붙이고, 미리보기에서 확인하세요. 다음 기준만 알아두면 시작할 수 있습니다.

시각은 영상 시작부터

표기뜻
02:352분 35초
1:02:351시간 2분 35초
60:0060분, 즉 1시간

초는 00–59로 씁니다. H:MM:SS의 분도 00–59입니다. 날짜나 실제 시계의 시각은 영상 시각과 다릅니다.

순간과 구간을 구분하세요

TEXT
- 02:35 다시 볼 순간
- 03:00 ~ 04:00 [M] 설명을 함께 보기
- 04:10 ~ 04:30 [H] 결정적인 장면
  • 시각 하나: 이동할 순간입니다. 다음 시각까지의 구간을 만들지 않습니다.
  • 시작과 끝: 시작보다 끝이 뒤여야 합니다.
  • 별·BEST: 작성자가 강조한 순간입니다. 컷으로 담을지는 직접 결정합니다.

구간과 강조의 화면 예제

주제 아래에 장면을 두세요

TEXT
# 00:00 ~ 20:00 첫 게임
## 01:00 ~ 10:00 첫 판
- 02:35 사건
## 10:00 ~ 18:00 두 번째 판

D1은 큰 주제, D2는 그 안의 장면, Point는 순간입니다. 더 깊은 제목은 바로 위 단계 아래에 둡니다. 제목은 #부터 ######까지 쓸 수 있습니다.

제목에 시작만 적으면 다음 제목이나 부모 구간·영상의 끝을 기준으로 끝을 계산합니다. 댓글이 잘렸거나 경계를 알 수 없으면 끝 미확정으로 남습니다. 직접 적은 끝은 유지합니다.

01:23 / 02:55 시작두 순간
01:23 ~ 02:55 [메모] 시작 구간하나의 범위
단독 ■ 또는 구분선앞 이야기와 구분된 새 목록

괄호 안의 시각이 실제 시작·정정·참고 중 무엇인지는 자동으로 정하지 않습니다.

이름으로 비교 영상 찾기

맨 위에 합방 : 이름 A, 이름 B만 적거나 장면 옆에 (w. 이름)을 붙이세요. 댓글·요약을 불러오면 이름을 자동 검색하고 고정 영상과 방송 시간이 겹치는 모든 다시보기를 목록에 불러옵니다. 같은 별칭을 서로 다른 사람에게 연결하지 않습니다.

목록에서 이름을 눌러 비교 영상을 여세요. 동명이인은 직접 선택할 수 있습니다. 같은 장면이 어긋나면 시각 보정을 사용합니다. 인물과 합방 예제

가져온 뒤 확인할 것

  1. 실제 영상의 시각인지 확인합니다.
  2. 주제·장면·순간이 의도대로 나뉘었는지 봅니다.
  3. 끝 미확정이나 오류 안내를 확인합니다.
