# 자료 공유하기

현재 기본 안내는 **CVA-탬패드 0.3.31**입니다. 이 버전에서는 시간표 JSON이나 작업 파일을 전달해 함께 볼 수 있습니다.

## 시간표를 전달하려면

1. 댓글 시각 목록을 TXT로 보내거나, [호환 시간표 JSON](files.md)을 준비합니다.
2. 받는 사람이 같은 다시보기에서 **자료 불러오기**로 파일을 엽니다.
3. D1·D2·Point, 강조·메모·관련 인물을 시간축에서 확인합니다.

ttaem.com에 게시하지 않아도 로컬 파일을 가져올 수 있습니다. [JSON 형식과 예제](files.md)에서 자세히 확인하세요.

## 컷 작업을 이어 보려면

작업실 상단의 **작업 파일 저장**으로 보관한 파일을 전달합니다. 받는 사람은 **작업 이어 열기**에서 해당 파일을 선택합니다. 영상 파일은 별도로 연결합니다.

## 공유 링크 미리보기

다시보기 주소에 시간표·합방·집계·컷 정보를 담아 여는 기능과 7일 단축 링크는 [0.3.32 미리보기](../versions/0.3.32/sharing.html)에서 볼 수 있습니다. **0.3.31에는 이 공유 메뉴가 없습니다.**
