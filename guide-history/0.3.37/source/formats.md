# 지원 형태 한눈에

같은 시각도 **순간**, **이야기 구간**, **관련 인물 단서**로 쓰일 수 있습니다. 아래 표는 현재 읽는 형태와 그 의미를 함께 보여 줍니다.


d1·d2·dn, point, 예상구간이 낯설다면 [시간축 읽는 법](timeline.md)을 먼저 보세요. 아래의 지원 표와 연결된 문서에는 댓글 원문과 시간축 결과 그림이 함께 있습니다.

## 시각과 기본 목록

| 형태 | 짧은 예제 | 읽는 의미 |
|---|---|---|
| 앞에 시각 | `02:35 첫 장면` | 하나의 순간 |
| 뒤에 시각 | `첫 장면 [02:35]` 또는 `첫 장면 - 02:35` | 하나의 순간 |
| 시각만 | `54:30` | 제목 없는 책갈피 |
| 여러 시각만 | `01:00 02:00 03:00` | 서로 다른 세 순간 |
| 설명 뒤 여러 시각 | `첫 장면 [01:00] 두 번째 장면 [02:00]` | 각 설명과 각 순간 |
| 선두 시각 괄호 | `[01:00] 시작`, `(01:00) 시작`, `【01:00】 시작` | 닫힌 시각 괄호 뒤 제목을 하나의 순간으로 읽기 |
| 번호 목록 | `1. 01:00 시작`, `2) [02:00] 이야기` | 번호만으로 목차 깊이를 만들지 않는 순간 목록 |
| 시각 뒤 콜론 | `01:00: 첫 장면`, `1) [01:00]: 첫 장면` | 완전한 시각과 뒤 제목을 구분 |
| 강조된 시각 | `**02:35**`, `__02:35__`, `*02:35*`, `_02:35_` 뒤에 설명 | 강조 기호를 벗겨 시각을 읽고 원문 보존 |
| 글머리표 | `- 02:35 장면`, `▶ 02:35 장면`, `• 02:35 장면` | 문맥에 따라 순간 또는 목차 항목 |
| 복수 시각 | `13:20 / 15:10 같은 장면` | 서로 다른 두 이동 지점 |
| 각 시각의 설명 | `01:00 첫 장면 / 02:00 두 번째 장면` | 각 시각과 각 설명 |
| 반복 시각 | `01:00 첫 설명` 다음 `01:00 다른 설명` | 별개의 원문 항목 두 개 |

시각은 `MM:SS` 또는 `H:MM:SS`입니다. 초는 두 자리 00–59이고, 세 부분 형식의 분도 00–59입니다. `60:00`은 1시간입니다. 주 항목에는 정수 초를 사용합니다.

**슬래시는 여러 순간, 물결표·대시는 범위**입니다. `13:20 / 15:10`을 13:20부터 15:10까지 재생하는 구간으로 바꾸지 않습니다. 괄호 안 시각은 별도 규칙이므로 [괄호 시각](existing.md#괄호-속-시각은-확인해-주세요)을 확인하세요.

## 목차와 구조

| 형태 | 짧은 예제 | 읽는 의미 |
|---|---|---|
| 명시 제목 | `# 01:00 게임`, `## 02:00 첫 판`, `#**01:00** 게임`, `##[02:00] 첫 판` | 주제·하위 구간, 깊이 1–6 |
| 자연 목차 | `01:00 게임` 다음 `- 02:00 첫 판`, `--02:10 사건` | 주제 d1 → 장면 d2 → 순간 |
| 분류 제목 | `💬 저챗` 다음 `01:00 등장` | 다음 실제 시각을 시작으로 쓰는 주제 |
| 트리 표기 | `└ 02:10 사건`, `ㄴ 02:10 사건` | 구조 안의 순간 |
| 명확한 들여쓰기 | `01:00 게임` 다음 `  02:00 첫 판` | 상대적인 안쪽 행을 하위 장면으로 추론 |
| 독립 목록 구분 | 단독 `■`, `---`, `***`, `___` 뒤의 새 시각 목록 | 앞 목록의 부모를 이어받지 않는 별도 목록 |

시각 괄호·번호·콜론은 기존 제목·들여쓰기·목록 구조와 함께 읽습니다. 붙은 `#`와 시각 강조를 해석할 때도 원문을 고치지 않습니다. **평평한 목록은 순간으로 유지**합니다. 빈줄이나 일반 문장만으로 주제·종료 시각을 만들지 않습니다. 자연 목차는 추론이라는 표시와 원문을 함께 확인할 수 있습니다. [상세 예제](existing.md)를 참고하세요.

## 구간, 강조, 보조 정보

| 형태 | 예제 | 의미·주의 |
|---|---|---|
| 명시 범위 | `- 02:00 ~ 03:00 [M] 설명` | 시작 포함·끝 제외 구간 |
| 범위만 적기 | `02:00 ~ 03:00 설명` | 메모 구간으로 읽기 |
| 순간 역할 | `[P]`, `[포인트]` | 하나의 순간 |
| 메모 | **`[M]` / `[메모]`** | 순간 또는 명시 범위 |
| 먼저 볼 곳 | `[W]` / `[볼 곳]` / `[먼저 보기]` | 순간 또는 명시 범위 |
| 하이라이트 | `[H]` / `[하이라이트]` | 끝이 있는 범위 |
| 예상 후보 | `[H?]` / `[예상]` | 끝이 있는 검토 전 후보 |
| 합방 범위 | `[합방]` | 끝이 있는 합방 맥락 |
| 작성자 강조 | `⭐`, `★`, 독립된 `BEST` | 작성자의 강조, 점수·승인 아님 |
| 부가 설명 | `설명:`, `맥락:`, `검토 상태:` | 직전 항목에 붙는 텍스트 |
| 떨어진 원본 구간 | `원본 구간: 02:00 ~ 03:00; 06:00 ~ 08:00` | 지정한 원본 부분만 보존 |
| 최상단 한 줄 명단 | `합방 : 가상A, 가상B`만 적기 | 문서 전체의 비교 조회 명단. 확정 참여 구간을 만들지 않음 |
| 합방 명단·자동 조회 | `합방: 가상A, 가상B` · `함께:` · `참여:` | 구간의 명단으로 방송인 자동 검색 · 겹치는 다시보기 자동 불러오기 |
| 제목 안의 합방 명단 | `# 01:00 게임 (합방: 가상A, 가상B)` | 제목 구간의 명단 |
| 관련 인물 | `(w. 가상A)`, `(w/ 가상A, 가상B)`, `(with 역할A(가상A))` | 방송인 자동 검색 · 겹치는 다시보기 자동 불러오기 |
| 괄호 안 여러 인물 | `02:10 만남 (가상A, 가상B)` | 마지막 괄호의 두 명 이상을 자동 검색 · 겹치는 다시보기 불러오기 |
| 원문별 별칭 | `별칭: 역할A = 가상A` | 같은 원문 안에서만 적용 |

영문 태그는 대소문자를 구분하지 않습니다. `[m]`도 `[M]`과 같습니다. 범위 사이에는 `~`, `-`, `–`, `—`를 쓸 수 있습니다.

관련 인물 괄호는 검색 단서이며 해당 구간 전체의 참석을 확정하지 않습니다. 합방 조회는 처음 12명과 **더보기** 다음 12명으로 이어집니다. 방송 시간대가 겹쳐도 같은 장면·정렬은 직접 확인하며, 일부 조회 상태에서 모든 영상의 발견을 보장하지 않습니다.

하이라이트·예상구간·합방 범위에는 시작과 끝을 적어 주세요. 기존 댓글에 끝이 없으면 미리보기 안내를 확인하세요. [구간과 강조](ranges.md), [인물과 합방](people.md)에서 경계를 설명합니다. [별이 보이는 모습](ranges.md#작성자-강조), [제목과 인물 칩](people.md#앱에서-제목과-인물-읽기)도 함께 확인하세요.
