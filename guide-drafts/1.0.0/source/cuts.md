# 컷 작업과 MP4 저장

원하는 장면을 **컷 담기**로 모은 뒤, 담은 순서대로 확인하고 MP4로 저장합니다. 원본 영상 파일을 따로 준비하지 않아도 다시보기를 출처로 선택할 수 있습니다.

아직 담은 컷이 없으면 다음 행동만 표시됩니다. 컷을 담으면 재생 도구와 목록이 나타나며, 각 컷의 제목 아래에서 출처·시작~끝·길이를 확인할 수 있습니다.

넓은 컷 작업 패널에서는 **편집 결과와 저장 카드**를 나란히 보고, 아래에서 컷 목록을 조절합니다. 좁은 패널에서는 편집 결과 → 담은 컷 → 저장 순서로 표시됩니다.

## 여러 다시보기를 원하는 순서로 담기

이 항목은 일반판 개발 설치 기준입니다. 출처 영상과 시작·끝을 정한 뒤 **새 컷 담을 위치**에서 **맨 뒤**, **맨 앞**, **선택한 컷 앞**을 고릅니다. 선택한 컷 앞에 넣으려면 먼저 그 컷을 선택하세요.

예를 들어 방송 후반 다시보기를 먼저 담았다면, 앞부분 다시보기를 출처로 고르고 **맨 앞**으로 담아 전체 순서를 맞출 수 있습니다. 담은 배열 순서가 미리보기·저장·출력 순서입니다. 방송 시각을 보고 자동으로 재정렬하지 않으며, 출처별 원본 시각은 그대로 유지합니다. **실행 취소/다시 실행**으로 삽입과 순서를 되돌릴 수 있습니다. 기존 컷 수정은 선택한 원래 자리를 보존합니다.

## 시작과 끝 조절하기

1. **컷 편집**에서 출처 영상과 시작·끝을 고르고 컷을 담습니다.
2. **컷 작업 → 담은 컷**에서 수정할 컷을 선택합니다.
3. `00:00:00 ~ 00:00:00`의 시작·끝을 직접 입력하거나 양끝 손잡이를 끕니다.
4. 경계의 영상을 확인하고 손을 놓으면 변경한 길이를 저장합니다. `Esc`로 조절을 취소할 수 있습니다.

일반판 개발 설치에서 장면을 먼저 선택한 뒤 **선택 장면으로**를 누르면 새 컷의 시작·끝 입력을 채웁니다. 순간 표식처럼 끝이 없는 장면은 끝을 직접 지정한 뒤 **컷 담기**를 누르세요.

손잡이에 초점을 두고 방향키로 1초, `Shift`와 방향키로 10초씩 조절할 수 있습니다. 시작은 끝보다 앞이어야 하며 출처 영상 길이를 넘길 수 없습니다. 컷 목록에는 출처 시각, 결과 재생바에는 **담은 컷 전체의 경과시간**이 표시됩니다.

일반판 개발 후보에는 선택한 다시보기의 길이를 먼저 확인하는 두 버튼이 있습니다.

| 버튼 | 동작 |
|---|---|
| 전체 영상 담기 | 선택한 출처의 0초부터 확인한 끝까지 새 컷으로 담음. **새 컷 담을 위치**의 맨 뒤·맨 앞·선택한 컷 앞 적용 |
| 영상 끝까지 지정 | 작성 중인 시작은 유지하고 끝만 지정. 시작을 확인한 뒤 **컷 담기**로 담음 |

확인하는 동안 관련 편집·출력은 잠기며 **확인 취소**로 멈출 수 있습니다. 실패하거나 취소하면 기존 초안과 컷을 유지합니다. 출처 전환을 취소했을 때도 기존 출처와 입력을 유지하며, 전환을 마치면 새 출처의 시작·끝을 다시 정합니다.

버튼으로 선택한 시각은 화면에 표시되는 값보다 정밀할 수 있습니다. 선택한 숫자는 컷 작업을 저장하고 다시 열거나 컷을 수정·나눌 때도 보존하며, 표시 자릿수에 맞춰 끝을 줄이거나 늘리지 않습니다. 시각을 직접 입력해 확정하면 그 입력값을 사용합니다. 같은 표시 값을 다시 확정한 경우도 새 입력으로 취급하며, `Esc`로 입력을 취소하면 이전의 정밀한 선택을 유지합니다. 가까운 영상 끝이나 키프레임으로 자동 이동시키는 기능은 아닙니다.

설치된 일반판의 메인 Chrome 검사에서 **전체 영상 담기 → 정밀 구간을 포함한 컷 작업 JSON 저장 → 실행 취소**, **영상 끝까지 지정 → 정밀 초안 JSON 저장**을 확인했습니다. 이 확인은 선택·저장 동작의 범위이며, 긴 다시보기 전체의 영상 출력이나 새 전체 소리 복사의 성공을 뜻하지 않습니다.

## 결과 확인하기

**편집 결과**에서 담은 순서대로 재생합니다. 결과의 구간 막대는 각 컷 길이에 비례합니다. 예를 들어 30초 컷과 5분 컷의 막대 길이는 1:10이고, 전체 길이는 5분 30초입니다.

선택한 컷의 제목 아래에는 **출처 영상의 시작·끝·길이**, 영상 위에는 **편집 결과의 재생 시간**이 표시됩니다.

목록에서 편집할 컷을 선택하는 동작과 전체 결과를 처음부터 재생하는 동작은 구분됩니다. 선택한 컷은 파란 테두리, 재생 중인 컷은 **재생 중** 표시로 구분합니다. 다른 컷을 선택해도 현재 재생은 이어집니다. **이 컷 보기**는 선택한 컷만, **처음부터 재생**은 담은 결과 전체를 재생합니다.

## 화질과 저장 방법

**컷 작업 → 영상·컷 목록 저장**에서 MP4 영상의 해상도와 압축을 선택합니다. 녹화 파일을 사용할 때만 **내 녹화본 연결**을 열면 됩니다.

| 선택 | 사용 방법 |
|---|---|
| 원본·1080p·720p·480p | 출력 해상도의 상한. 작은 원본을 확대하지 않고 비율을 유지 |
| 표준·높은 화질·작은 파일 | 같은 해상도에서 화질과 파일 크기를 조절 |
| 일반 다운로드 | 작은 결과를 브라우저 다운로드로 저장. 최대 128 MiB. 큰 결과는 생성 전에 저장 방법을 안내 |
| 직접 파일 저장 · 긴 영상에 권장 | 먼저 저장 위치를 고르고 파일에 이어 쓰기. 긴 결과에는 이 방법 권장 |
| YouTube Studio로 전달 | 일반판 개발 설치에서 연결된 채널 탭으로 완성 영상을 직접 전달. 출력 파일의 별도 다운로드·재선택 없이 진행 |

**저장 방법**에서 일반 다운로드 또는 직접 파일 저장을 선택한 뒤 **담은 컷 MP4 저장**을 누릅니다. 직접 저장은 먼저 저장 위치를 고릅니다. 원본을 덮어쓰지 않도록 새 파일 이름을 선택하세요.

파일 크기는 길이·내용·화질에 따라 달라지며, 예상 크기와 완성 파일의 실제 크기는 다를 수 있습니다. 예상 크기가 128 MiB 이상이면 생성 전에 안내합니다. 직접 저장을 선택하거나 화질·컷 길이를 줄일 수 있습니다. 일반 다운로드를 계속하려면 안내에 나타난 **예상 크기와 관계없이 일반 다운로드 진행**을 선택한 뒤 같은 저장 버튼을 누릅니다. 이 경우에도 실제 128 MiB 제한은 유지되며, 한도를 넘은 출력은 완료로 표시하지 않습니다.

### 가능하면 원본 영상 그대로 저장

이 선택은 일반판 개발 후보의 기능입니다. 설치 빌드에 따라 제공 범위가 다르며, 치지직 다시보기의 일부 지원 구간은 1080p60 실제 저장 파일에서 영상·시각·소리 구조 검사를 통과했습니다. 전체 다시보기와 모든 컷의 원본 저장을 뜻하지 않습니다.

새 일반판 작업은 **가능하면 원본 영상 그대로 저장**이 켜진 상태로 시작합니다. 다시보기나 연결한 녹화본의 컷이 복사 조건을 만족하는지 먼저 검사하고, 가능한 경우 영상은 다시 압축하지 않고 복사합니다. 소리는 보통 **컷 경계에 맞게 정밀하게 자른 뒤 AAC로 다시 생성**하므로 원본 오디오 샘플이 그대로 보존되지는 않습니다.

편집자용의 새 개발 후보는 Export와 Quick Export의 새 작업에서 **원본 유지**를 켜고 복사 조건을 먼저 검사합니다. 이전 후보의 기본 꺼짐과 구분되는 변경입니다. 이미 끈 원본 유지 선택과 이전 형식의 설정, 직접 고른 처리 프리셋·영상 설정·출력 범위는 유지합니다. 처리 프리셋이나 영상 설정을 직접 고르면 그 처리 의도를 우선하며, 원본 우선으로 바꾸려면 **원본 유지**를 다시 켭니다.

현재 편집·원본·정확한 출력 구간의 복사 조건이 맞을 때 **영상은 다시 압축하지 않고 복사**하며, 소리는 기존 native 편집 결과에 맞춰 AAC로 생성합니다. 효과·크기 변경 등 기존 처리 판정은 유지하며, 복사를 준비하는 동안에는 같은 출력 작업에서 첫 압축 프레임을 비동기로 확인합니다. 시작이 복사 키프레임 조건 밖이라는 확실한 판정은 원본 읽기와 반납이 끝난 뒤 파일 쓰기 전에 기존 처리 설정·범위로 전환하지만, 확인 불가·원본 변경·취소·손상이나 복사 시작 뒤 오류는 중단합니다. 원본 유지 중에는 대기열에 추가할 수 없습니다. 새 로컬 저장은 먼저 저장 위치를 고르고, 실제 파일 쓰기 완료를 확인한 뒤 임시 원본을 정리하는 경로를 사용합니다.

이 후보는 **고정된 편 길이와 실제 출력 끝·파일 닫기 완료가 함께 확인된 결과에만 추가 파일 재묶기(remux)를 생략**합니다. 증명이 없거나 맞지 않으면 기존 마무리 검사·재묶기를 유지합니다. 첫 프레임 확인 수리의 소스 회귀·빌드·재현은 확인했으며, 새 설치·실제 완성 파일·전체 소리 검증은 별도로 남아 있습니다. 따라서 현재 설치된 개발 후보의 출력 안전성과 전체 수락은 완료되지 않았습니다. Studio 연결 확인도 파일 완성·전달·업로드 완료의 증거가 아닙니다. 일반판의 실제 출력 관측을 편집자용의 검증 결과로 해석하지 마세요.

새 개발 후보는 최종 출력 구간이 **변경 없는 한 다시보기 전체**이고 영상·소리 설정과 연속된 시각이 맞는 경우에만 원본 AAC 소리 복사도 검사합니다. 조건이 맞으면 **원본 소리 복사**로 안내하고, 실제 저장 완료는 영상과 소리 양쪽의 끝 검증을 모두 통과한 뒤 표시합니다. 그 밖의 소리는 기존 AAC 재생성을 사용합니다. 이 추가 기능은 소스·자동 검사 기준이며, 실제 치지직 전체 출력이나 설치된 일반판에서 확인한 결과는 아직 없습니다.

**압축 품질을 직접 바꾸면 원본 우선이 해제**되어 선택한 품질로 생성합니다. 이전에 저장한 작업을 열 때는 저장된 출력 설정을 유지하므로, 압축해 저장하려던 작업이 새 기본값으로 바뀌지 않습니다. 원본 우선으로 바꾸려면 이 선택을 직접 켜세요.

일부 H.264 MP4와 치지직 다시보기의 지원 구간이 대상이며, 안전한 키프레임 경계와 같은 영상 설정이 필요합니다. 다시보기 후보는 확인된 IDR 키프레임에서 시작해 다음 확인된 IDR 키프레임에서 끝나는 범위를 검사합니다. 같은 다시보기에서 앞 컷의 끝과 다음 컷의 시작이 정확히 이어지면, 담은 컷 목록을 유지하면서 내부적으로 한 구간으로 묶어 검사할 수 있습니다.

개발 빌드는 **다시보기의 처음부터 담기**, **중간 키프레임부터 출처 끝까지 담기**, **여러 다시보기를 담은 순서대로 잇기**의 복사 조건도 검사합니다. 처음부터 담을 때는 영상과 소리의 원래 시작 시각 차이를 유지합니다. 처음부터 읽은 구간과 중간부터 읽은 끝 구간은 각각 출처의 끝까지 확인할 수 있어야 합니다. 여러 출처를 이을 때도 영상 설정과 연결 경계가 모두 맞아야 합니다.

메인 Chrome의 짧은 합성 영상 검사에서 **1080p60 원본 전체 저장**과 **같은 원본을 두 출처로 이어 저장**한 파일의 영상 내용·시각을 확인했습니다. 설치된 일반판의 원본 우선 선택과 Studio 저장 선택 표시도 별도로 확인했습니다. 전체·연결 파일 검사는 검증 화면에서 수행했으며, 모든 실제 다시보기나 일반판의 새 Studio 업로드를 검증한 것은 아닙니다.

이후 설치된 일반판의 **담은 컷 MP4 저장**으로 서로 다른 다시보기의 앞·끝 구간을 이은 약 2분 5초 파일과 순서를 바꾼 파일을 실제 저장했습니다. 두 순서 모두 1080p60 영상의 모든 압축 프레임 내용·시각과 디코딩한 화면이 원본과 일치했습니다. 소리는 별도로 처리되며, 시작부와 일부 끝 경계의 검증이 남아 있습니다. 긴 다시보기 전체 저장이나 압축 출력과의 속도 비교까지 확인한 것은 아닙니다.

마지막 영상보다 소리가 더 길면 **요청한 끝까지 원본 소리가 있고 결과 소리도 끝까지 처리됐는지** 확인해야 저장을 완료합니다. 생성 전 검사에서 복사 조건이 맞지 않으면 기존 정밀 출력을 사용하고, 복사 도중 끝 검증에 실패하면 미완성 출력을 중단하고 컷 목록을 유지합니다. 소리를 다시 생성하는 경우의 끝 검사는 원본 오디오 샘플을 그대로 보존한다는 뜻이 아닙니다.

**59.94fps 영상은 현재 원본 영상 복사를 지원하지 않으며 기존 정밀 출력으로 생성**합니다. 생성 전 검사에서 해상도를 바꾸어야 하거나 컷 경계·파일 형식·영상 설정이 지원되지 않으면 **선택한 해상도·압축 품질로 정확하게 생성**합니다. 복사를 위해 담은 컷의 시작이나 끝을 가까운 키프레임으로 옮기지 않습니다. [자세한 조건](limits.md#원본-영상-복사를-선택했을-때)을 확인하세요.

복사되는 영상에는 압축 품질 선택이 적용되지 않으므로 원본보다 작은 파일이 된다는 보장은 없습니다. 파일을 작게 만들려면 해상도·압축 품질을 조절하세요. 압축 품질을 바꾸면 원본 우선이 해제됩니다. 일부 로컬 녹화 파일은 검사 과정에서 파일 앞부분을 추가로 읽을 수 있습니다. 치지직 다시보기는 목록·초기 영상 설정과 필요한 구간을 읽습니다. 선택을 켰다고 항상 빨라지는 것은 아닙니다.

원본 영상 복사 도중 조건 불일치가 발견되면 미완성 파일 생성을 중단하고 컷 목록을 유지합니다. 자동으로 다시 압축해 생성하지 않으므로, 안내를 확인한 뒤 원본 우선을 끄고 다시 저장할 수 있습니다.

상태에 **원본 복사 조건 확인 중**이 표시된 뒤 영상 복사 또는 재생성 이유를 확인할 수 있습니다. 영상 복사 중 소리를 다시 만들 때는 **원본 영상 복사 · 소리는 컷에 맞춰 다시 생성**, 위의 전체 소리 복사 조건을 만족하면 **원본 영상 복사 · 원본 소리 복사**로 안내합니다. 소리가 없는 원본에는 소리 처리 문구를 표시하지 않습니다. 재생성할 때는 컷 경계, 선택한 크기·방향, 원본 영상 설정 차이 등의 이유를 표시합니다. 이 선택은 MP4를 만드는 방법에 적용되며, 일반 다운로드·직접 파일 저장·연결된 Studio 전달은 기존 저장 방법을 그대로 사용합니다. Studio 전달 뒤 업로드·고화질 처리·게시는 각각 확인하세요.

## 0KB로 보일 때

저장 카드에는 **준비 → 영상 생성 → 마무리 → 완료**가 표시됩니다. 생성 중에는 백분율과 처리한 길이, 생성 데이터 크기를 볼 수 있습니다. 마무리 단계가 끝나야 완료로 표시됩니다.

개발 설치에서 출력 편의 처리 길이·크기가 아직 도착하지 않았으면 **영상 생성 준비 중**으로 표시합니다. 처리값이 도착하면 진행 표시가 이어집니다. 준비 표시만으로 파일이 완성된 것은 아니며, 실제 오류나 취소는 아래 상태 안내로 구분합니다.

직접 저장 중 파일이 0KB로 보일 수 있습니다. **MP4 저장 완료** 뒤 파일을 여세요. 생성 데이터 크기는 디스크에 저장이 끝난 파일 크기와 다를 수 있습니다.

영상 생성을 취소하면 **MP4 생성 취소 · 완성 파일이 아닙니다**가 표시됩니다. 컷 목록은 유지되며 다시 저장할 수 있습니다. 영상 생성 오류는 **생성 실패**, Studio 연결·전달 오류는 **Studio 전달 실패**로 구분합니다. 안내된 원인을 확인한 뒤 생성 설정을 조절하거나 같은 출력에서 전달을 이어가세요.

## YouTube Studio로 직접 보내기

1. 업로드할 채널의 **YouTube Studio** 탭을 열고 대시보드에 둡니다.
2. 탬패드의 **영상·컷 목록 저장 → YouTube Studio로 전달**을 선택합니다.
3. **탭 연결 확인**을 눌러 연결할 채널을 확인합니다. 탭이 여러 개라면 전달할 탭을 선택한 뒤 다시 확인합니다.
4. 출력 출처·해상도·담은 컷 순서를 확인한 뒤 **담은 컷 YouTube로 전달**을 누릅니다.
5. 편별 생성·업로드 상태와 완료 링크를 확인합니다. 최종 제목·시청자층·공개 여부와 게시는 Studio에서 검토합니다.

Studio 탭을 나중에 열었다면 탬패드로 돌아와 **탭 연결 확인**을 눌러 현재 채널 목록을 확인하세요. 전달할 채널과 수신기 연결 상태를 확인한 뒤 전달합니다. 목록 조회나 연결 확인만으로 파일을 생성하거나 업로드하지 않습니다.

일부 지원 구간에서는 일반판의 정상 전달 버튼으로 결과 파일을 다시 선택하지 않고 Studio에 전달해 비공개 저장·업로드·처리가 완료되는 것을 확인했습니다. 해당 비공개 영상의 YouTube 재생 화질 메뉴에서 **1080p60 HD·720p60** 선택 항목도 확인했습니다. 이 확인이 모든 영상·컷의 지원이나 다른 영상의 고화질 처리 완료를 보장하지는 않습니다.

**탭 연결 확인**은 선택한 Studio 탭의 수신기에 연결할 수 있는지 확인하는 단계입니다. **Studio 수신기 연결 확인됨**을 확인하세요. 빈 업로드 화면은 **담은 컷 YouTube로 전달**을 눌러 실제로 전달할 때 검사합니다. 기존 업로드나 입력 파일이 있으면 내용을 보존하고 중단합니다.

확장을 업데이트하거나 다시 불러온 뒤 기존 Studio 탭의 수신기에 연결할 수 없으면, 기존 탭을 보존하고 같은 채널의 새 Studio 탭에 연결해 복구합니다. 화면에 표시된 연결 채널을 확인하세요. 수신기 연결이 복구됐다는 표시와 영상 업로드 완료는 별도로 확인해야 합니다.

기존 전달 기록이 남아 있으면 **탭 연결 확인**은 새 탭을 찾거나 연결하지 않고 기존 작업을 유지합니다. 원래 설정으로 같은 전달을 재시도하거나 **준비한 출력 편 정리** 후 새 전송을 시작하세요.

원본이1080p·60fps를 제공할 때 그 화질과 프레임 시각을 유지합니다. 낮은 해상도나 프레임률의 원본을1080p60으로 바꾸는 기능은 아닙니다. 내 녹화본을 출처로 쓰면 처음 원본 연결은 필요하지만, 생성한 결과 파일을 다시 선택할 필요는 없습니다.

### 긴 결과의 자동 분할과 순차 업로드

한 편은 YouTube의 최대12시간 또는256GB 한도 안에서 준비합니다. 실제 MP4 길이·바이트를 검사하며, 브라우저에 남은 임시 저장 공간이 작으면 더 짧게 나눕니다. 따라서17시간 방송이 항상 두 편으로 나뉘는 것은 아닙니다. 편의 끝과 다음 편의 시작은 같은 결과 시각으로 이어집니다. 출력용 분할은 편집 컷 목록이나 실행 취소 기록을 바꾸지 않습니다.

개발 빌드는 원본 영상 복사를 선택한 지원 구간에서 **자동 분할에 필요한 편 사이 경계**를 한도 안의 확인된 키프레임으로 정합니다. 직접 담은 컷의 시작·끝이나 순서를 옮기는 기능은 아닙니다. 적절한 경계를 확인할 수 없으면 기존 정밀 생성 경로를 사용합니다. 재시도할 때는 이미 정한 편의 구간과 전달 기록을 유지하며, 실제 크기 초과 등으로 다시 나눠야 할 때도 아직 전달하지 않은 출력만 조정합니다.

메인 Chrome 검증 화면의 작은 **6fps 합성 영상**에서는 시간 한도에 따라 두 편으로 나누고, 재생성 없이 보관한 같은 파일로 재시도하는 흐름과 두 출력 파일을 확인했습니다. 이때 수신기는 테스트용이며 실제 Studio 업로드는 하지 않았습니다. 임시 공간 부족을 일으킨 분할이나 전체17시간 처리를 검증한 것은 아닙니다. 소리는 AAC로 다시 생성하므로 원본 오디오의 샘플 동일성이나 입모양 동기를 보장하지 않습니다. [소리 검사의 한계](limits.md#원본-영상-복사를-선택했을-때)도 확인하세요.

한 편을 만든 뒤 Studio로 전송하고 **업로드 완료·비공개 저장·영상 링크**를 확인한 다음 다음 편을 만듭니다. 이전 편의 임시 파일은 이 과정에서 정리됩니다. 마지막 업로드 창은 검토하도록 남깁니다. 브라우저를 열어 두고 네트워크 연결을 유지하세요. 업로드 완료와 고화질 처리 완료는 서로 다를 수 있습니다.

개발 후보는 현재 편의 **업로드·처리 진행**, **비공개 저장 대기**, **필수 시청자층 정보 확인**을 구분해 안내합니다. 필수 정보 안내가 나오면 Studio에서 영상의 시청자층을 직접 지정하고 비공개 저장을 마치세요. Studio 조작으로 자동 진행이 멈추면 탬패드의 같은 전달 버튼으로 이어갑니다. 이미 준비한 같은 파일을 사용하며, 확인되지 않은 상태를 완료로 표시하지 않습니다. 이 안내의 소스 회귀와 설치된 Chrome의 실제 반영·비공개 수락은 각각 별도로 검증합니다.

### 중지하거나 다시 이어갈 때

생성 취소나 실패는 컷 목록을 지우지 않습니다. 같은 출력 상태에서 다시 전달하면 이미 업로드된 편을 다시 보내지 않고 이어갑니다. Studio 업로드 창을 직접 조작하면 자동 진행을 멈춥니다. 내용을 확인한 뒤 탬패드에서 명시적으로 이어가세요.

연결 복구나 재시도 때문에 이미 보낸 편을 새 탭에 다시 보내지는 않습니다. Studio 문서를 새로고침하거나 닫아 수신 기록이 사라지면 중복 업로드 방지를 위해 자동 재전송하지 않습니다. 전달 여부를 확인할 수 없는 편은 기존 업로드를 Studio에서 먼저 확인하세요.

**준비한 출력 편 정리**는 이 출력의 임시 파일과 재시도 기록을 정리합니다. 원본 영상·컷 목록·Studio에 이미 연결·업로드한 파일은 유지되며, 다음 전달은 새 전송으로 처음부터 시작합니다.

## 편집자용 Export·Quick Export의 Studio 연결

편집자용 개발 후보는 Export와 Quick Export 양쪽에 **Studio 열기**와 **연결 확인**을 제공합니다. 개발 설치본의 Chrome에서 두 진입의 연결과 설정 보존을 확인했습니다. 실제 영상의 최소 처리·파일·소리·Studio 전달 수락은 별도로 남아 있습니다.

1. YouTube 영역에서 사용할 채널을 확인합니다. 채널 ID나 Studio 채널 주소를 직접 입력할 수 있습니다.
2. **Studio 열기**로 Studio를 엽니다. 채널을 아직 정하지 않았다면 열린 Studio에서 채널을 고른 뒤 돌아와 **연결 확인**을 누릅니다.
3. 같은 채널의 탭이 여러 개라 대상을 정하지 못하면 **Studio 열기**로 이 작업에 쓸 새 탭을 선택합니다. 기존 탭이나 진행 중인 업로드는 그대로 둡니다.

열기와 연결 확인만으로 파일을 생성·전달하거나 업로드하지 않습니다. 선택한 출력 프리셋·범위·원본 유지 설정도 바뀌지 않습니다. 연결을 확인한 뒤 출력 설정과 범위를 검토하고 **YouTube로 내보내기**를 선택합니다. 이미 준비한 전달의 재시도는 원래 작업을 이어가며, 연결을 열었다는 이유로 같은 파일을 새 탭에 다시 보내지 않습니다. 연결 성공과 실제 업로드·처리 완료는 별도로 확인하세요.
