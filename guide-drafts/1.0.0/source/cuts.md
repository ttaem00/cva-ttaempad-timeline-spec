# 컷 작업과 MP4 저장

원하는 장면을 **컷 담기**로 모은 뒤, 담은 순서대로 확인하고 MP4로 저장합니다. 원본 영상 파일을 따로 준비하지 않아도 다시보기를 출처로 선택할 수 있습니다.

아직 담은 컷이 없으면 다음 행동만 표시됩니다. 컷을 담으면 재생 도구와 목록이 나타나며, 각 컷의 제목 아래에서 출처·시작~끝·길이를 확인할 수 있습니다.

넓은 컷 작업 패널에서는 **편집 결과와 저장 카드**를 나란히 보고, 아래에서 컷 목록을 조절합니다. 좁은 패널에서는 편집 결과 → 담은 컷 → 저장 순서로 표시됩니다.

## 여러 다시보기를 원하는 순서로 담기

이 항목은 일반판 개발 설치 기준입니다. 출처 영상과 시작·끝을 정한 뒤 **새 컷 담을 위치**에서 **맨 뒤**, **맨 앞**, **선택한 컷 앞**을 고릅니다. 선택한 컷 앞에 넣으려면 먼저 그 컷을 선택하세요.

예를 들어 방송 후반 다시보기를 먼저 담았다면, 앞부분 다시보기를 출처로 고르고 **맨 앞**으로 담아 전체 순서를 맞출 수 있습니다. 담은 배열 순서가 미리보기·저장·출력 순서입니다. 방송 시각을 보고 자동으로 재정렬하지 않으며, 출처별 원본 시각은 그대로 유지합니다. **실행 취소/다시 실행**으로 삽입과 순서를 되돌릴 수 있습니다. 기존 컷 수정은 선택한 원래 자리를 보존합니다.

## 시작과 끝 조절하기

1. **컷 편집**에서 출처 영상과 시작·끝을 고르고 컷을 담습니다.
2. **컷 작업 → 담은 컷**에서 수정할 컷을 선택합니다.
3. `00:00:00 ~ 00:00:00`의 시작·끝을 직접 입력하거나 양끝 손잡이를 끕니다.
4. 경계의 영상을 확인하고 손을 놓으면 변경한 길이를 저장합니다. `Esc`로 조절을 취소할 수 있습니다.

손잡이에 초점을 두고 방향키로 1초, `Shift`와 방향키로 10초씩 조절할 수 있습니다. 시작은 끝보다 앞이어야 하며 출처 영상 길이를 넘길 수 없습니다. 컷 목록에는 출처 시각, 결과 재생바에는 **담은 컷 전체의 경과시간**이 표시됩니다.

## 결과 확인하기

**편집 결과**에서 담은 순서대로 재생합니다. 결과의 구간 막대는 각 컷 길이에 비례합니다. 예를 들어 30초 컷과 5분 컷의 막대 길이는 1:10이고, 전체 길이는 5분 30초입니다.

선택한 컷의 제목 아래에는 **출처 영상의 시작·끝·길이**, 영상 위에는 **편집 결과의 재생 시간**이 표시됩니다.

목록에서 편집할 컷을 선택하는 동작과 전체 결과를 처음부터 재생하는 동작은 구분됩니다. 선택한 컷은 파란 테두리, 재생 중인 컷은 **재생 중** 표시로 구분합니다. 다른 컷을 선택해도 현재 재생은 이어집니다. **이 컷 보기**는 선택한 컷만, **처음부터 재생**은 담은 결과 전체를 재생합니다.

## 화질과 저장 방법

**컷 작업 → 영상·컷 목록 저장**에서 MP4 영상의 해상도와 압축을 선택합니다. 녹화 파일을 사용할 때만 **내 녹화본 연결**을 열면 됩니다.

| 선택 | 사용 방법 |
|---|---|
| 원본·1080p·720p·480p | 출력 해상도의 상한. 작은 원본을 확대하지 않고 비율을 유지 |
| 표준·높은 화질·작은 파일 | 같은 해상도에서 화질과 파일 크기를 조절 |
| 일반 다운로드 | 작은 결과를 브라우저 다운로드로 저장. 최대 128 MiB. 큰 결과는 생성 전에 저장 방법을 안내 |
| 직접 파일 저장 · 긴 영상에 권장 | 먼저 저장 위치를 고르고 파일에 이어 쓰기. 긴 결과에는 이 방법 권장 |
| YouTube Studio로 전달 | 일반판 개발 설치에서 연결된 채널 탭으로 완성 영상을 직접 전달. 출력 파일의 별도 다운로드·재선택 없이 진행 |

**저장 방법**에서 일반 다운로드 또는 직접 파일 저장을 선택한 뒤 **담은 컷 MP4 저장**을 누릅니다. 직접 저장은 먼저 저장 위치를 고릅니다. 원본을 덮어쓰지 않도록 새 파일 이름을 선택하세요.

파일 크기는 길이·내용·화질에 따라 달라집니다. 예상 크기가 128 MiB 이상이면 생성 전에 안내합니다. 직접 저장을 선택하거나 화질·컷 길이를 줄일 수 있습니다. **예상 크기와 관계없이 일반 다운로드 진행**을 선택해도 실제 128 MiB 제한은 유지됩니다.

### 지원되는 구간은 원본 영상 복사

이 선택은 일반판 개발 후보에서 준비 중입니다. 현재 공개된 안내의 지원 범위와 설치된 빌드의 제공 여부는 별도로 확인해야 합니다.

출처를 **내 녹화본**으로 정하고 MP4 파일을 연결하면 **지원되는 구간은 원본 영상 복사**를 선택할 수 있습니다. 기본값은 꺼짐입니다. 켜면 담은 컷 전체가 복사 조건을 만족하는지 먼저 검사하고, 가능한 경우 영상은 다시 압축하지 않고 복사합니다. **소리는 컷 경계에 맞게 정밀하게 자른 뒤 AAC로 생성**합니다.

현재는 일부 H.264 MP4의 안전한 키프레임 경계와 영상 설정이 같은 구간만 지원합니다. 해상도를 바꾸어야 하거나, 컷 경계·파일 형식·영상 설정이 지원되지 않으면 **선택한 해상도·압축 품질로 정확하게 생성**합니다. 복사를 위해 담은 컷의 시작이나 끝을 가까운 키프레임으로 옮기지 않습니다. [자세한 조건](limits.md#원본-영상-복사를-선택했을-때)을 확인하세요.

복사되는 영상에는 압축 품질 선택이 적용되지 않으므로 원본보다 작은 파일이 된다는 보장은 없습니다. 파일을 작게 만들려면 이 선택을 끄고 해상도·압축 품질을 조절하세요. 복사 조건 검사에는 원본 시작부터 필요한 구간까지 추가 읽기가 있으며, 선택을 켰다고 항상 빨라지는 것은 아닙니다.

상태에 **원본 복사 조건 확인 중**, **원본 영상 복사 · 소리 정밀 처리**, **선택한 해상도·압축 품질로 생성**이 표시됩니다. 이 선택은 MP4를 만드는 방법에 적용되며, 일반 다운로드·직접 파일 저장·연결된 Studio 전달은 기존 저장 방법을 그대로 사용합니다. Studio 전달 뒤 업로드·고화질 처리·게시는 각각 확인하세요.

## 0KB로 보일 때

저장 카드에는 **준비 → 영상 생성 → 마무리 → 완료**가 표시됩니다. 생성 중에는 백분율과 처리한 길이, 생성 데이터 크기를 볼 수 있습니다. 마무리 단계가 끝나야 완료로 표시됩니다.

직접 저장 중 파일이 0KB로 보일 수 있습니다. **MP4 저장 완료** 뒤 파일을 여세요. 생성 데이터 크기는 디스크에 저장이 끝난 파일 크기와 다를 수 있습니다.

취소하면 **MP4 생성 취소 · 완성 파일이 아닙니다**가 표시됩니다. 컷 목록은 유지되며 다시 저장할 수 있습니다. 실제 오류는 **생성 실패**로 구분합니다. 실패했다면 저장 방법이나 화질을 바꾸어 다시 시도하세요.

## 패널 높이 바꾸기

오른쪽 **장면 찾기·장면 상세·컷 편집** 패널 아래 손잡이를 끌어 높이를 조절합니다. 방향키로도 조절할 수 있고, `Enter` 또는 두 번 누르기로 기본 높이로 돌아갑니다. 패널 제목으로 순서를 바꾸는 동작과 아래 손잡이로 높이를 바꾸는 동작은 별개입니다.

## YouTube Studio로 직접 보내기

1. 업로드할 채널의 **YouTube Studio** 탭을 열고 대시보드에 둡니다.
2. 탬패드의 **영상·컷 목록 저장 → YouTube Studio로 전달**을 선택합니다.
3. **탭 연결 확인**을 누르고 전송할 채널 탭을 직접 선택합니다.
4. 출력 출처·해상도·담은 컷 순서를 확인한 뒤 **담은 컷 YouTube로 전달**을 누릅니다.
5. 편별 생성·업로드 상태와 완료 링크를 확인합니다. 최종 제목·시청자층·공개 여부와 게시는 Studio에서 검토합니다.

연결된 탭의 빈 업로드 화면을 확인해 사용합니다. 기존 업로드나 파일이 있으면 덮어쓰지 않고 중단합니다. 원본이1080p·60fps를 제공할 때 그 화질과 프레임 시각을 유지합니다. 낮은 해상도나 프레임률의 원본을1080p60으로 바꾸는 기능은 아닙니다. 내 녹화본을 출처로 쓰면 처음 원본 연결은 필요하지만, 생성한 결과 파일을 다시 선택할 필요는 없습니다.

### 긴 결과의 자동 분할과 순차 업로드

한 편은 YouTube의 최대12시간 또는256GB 한도 안에서 준비합니다. 실제 MP4 길이·바이트를 검사하며, 브라우저에 남은 임시 저장 공간이 작으면 더 짧게 나눕니다. 따라서17시간 방송이 항상 두 편으로 나뉘는 것은 아닙니다. 편의 끝과 다음 편의 시작은 같은 결과 시각으로 이어집니다. 출력용 분할은 편집 컷 목록이나 실행 취소 기록을 바꾸지 않습니다.

한 편을 만든 뒤 Studio로 전송하고 **업로드 완료·비공개 저장·영상 링크**를 확인한 다음 다음 편을 만듭니다. 이전 편의 임시 파일은 이 과정에서 정리됩니다. 마지막 업로드 창은 검토하도록 남깁니다. 브라우저를 열어 두고 네트워크 연결을 유지하세요. 업로드 완료와 고화질 처리 완료는 서로 다를 수 있습니다.

### 중지하거나 다시 이어갈 때

생성 취소나 실패는 컷 목록을 지우지 않습니다. 같은 출력 상태에서 다시 전달하면 이미 업로드된 편을 다시 보내지 않고 이어갑니다. Studio 업로드 창을 직접 조작하면 자동 진행을 멈춥니다. 내용을 확인한 뒤 탬패드에서 명시적으로 이어가세요.

Studio 문서를 새로고침하거나 닫아 수신 기록이 사라지면 중복 업로드 방지를 위해 자동 재전송하지 않습니다. 기존 업로드를 Studio에서 먼저 확인하세요. **준비한 출력 편 정리**는 이 출력의 임시 준비 파일만 정리하며 원본 영상·컷 목록·이미 생성된 Studio 영상을 삭제하지 않습니다.
