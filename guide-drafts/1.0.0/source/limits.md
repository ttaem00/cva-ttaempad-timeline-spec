# 한계와 문제 해결

> **작성 기준:** 일반판과 **CVA-TTaempad pro**는 **0.n 개발 단계**이며 현재 개발 패키지 버전은 **0.4.0**입니다. 0.4.0 개발 패키지는 설치했으며, 발견된 문제의 후속 수정과 실사용 검증은 진행 중입니다. 이 초안 경로의 `1.0.0`은 과거 목표·문서 식별자로, 제품 1.0.0 공개·출시를 뜻하지 않습니다. 제품 1.0.0 출시와 전체 기능 수락은 **NOT_DONE**입니다.

미리보기에서 안내가 보이면 **원문과 시각부터 확인**하세요. 한 행에 오류가 있어도 나머지 정상 시각은 보존합니다.

자동 자막 생성은 현재 지원 기능에 포함하지 않습니다.

## 안내별 확인 방법

| 상황 | 확인할 일 |
|---|---|
| `01:23 시작 (02:55)` | 두 순간인지 구간인지 확인. 자동 이동 지점은 앞 시각 01:23 |
| `12:99`처럼 잘못된 시각 | 초는 00–59. 시각은 `MM:SS` 또는 `H:MM:SS`의 정수로 작성 |
| 부모 제목 누락 | `##` 앞에 해당 `#` 제목이 있는지 확인 |
| 하이라이트 끝 없음 | 시작·끝을 쓰거나 순간으로 바꾸기 |
| 끝 미확정 | 댓글 전체를 가져왔는지, 다음 경계·영상 길이를 알 수 있는지 확인 |
| 같은 시각·역순 시각 | 별개 항목이므로 원문 설명과 순서 확인 |
| 자연 구조 추론 · 역할/구간 확인 필요 | 제목과 판·순간이 의도대로 연결됐는지 미리보기 확인. 추론한 구조를 자동 채택하지 않음 |
| 명단 소속 확인 | 앞뒤 독립 합방 중 어느 쪽 명단인지 원문 확인. 조회 기간을 임의로 만들지 않음 |
| 빈 이름·빈 팀·닫히지 않은 명단 괄호 | 해당 명단 행을 확인. VS 글자나 다른 설명을 대신 인물로 찾지 않음 |
| 모르는 태그 | [지원 형태](formats.md)와 비교 |
| 손상된 D1·D2 또는 잘린 범위 끝 | 원문·확인 안내를 확인. 영향을 받는 끝은 미확정이고 이전 부모·명단은 손상 경계를 넘어 이어지지 않음 |
| 일부 조회·영상 미연결 | 이미 확인한 영상은 유지. 이름을 확인하거나 다시 조회. 영상이 없다는 확정이 아님 |
| 현재 명단에 이전 멤버가 안 보임 | 현재 합방 범위·없음·미확인 확인. 전체 멤버에서 등록 내역 확인 |
| 12명 다음 멤버가 안 보임 | **더보기**로 다음 12명 조회·펼치기. 원본 영상은 인원에 포함하지 않음 |
| 채널 이름 일치/신원 미확인 | 자동 후보의 실제 방송인 확인. 동률·팔로워 수치 미확인은 임의 선택하지 않음 |
| 성인·로그인·유료·차단 안내 | 공개 메타데이터 조회와 공식 재생 조건은 별개 |
| 합방 비교 영상이 검게 보임 | 기존 컷·초안을 보존하고 공식 원본의 접근·실제 재생 상태 확인. 정상 닫기·재열기 뒤 일부 비교 영상이 돌아온 관찰은 있으나 최초 원인은 UNKNOWN이며 근본 수리가 확인된 것은 아님 |

## 가장 명확하게 쓰려면

```text
# 00:00 ~ 10:00 첫 게임
## 01:00 ~ 05:00 첫 판
- 02:35 다시 볼 순간
- 03:00 ~ 03:20 [H?] 검토할 장면
```

- 시각은 줄 앞에 쓰고 설명을 붙입니다.
- 여러 순간은 `/`, 범위는 `~`로 구분합니다.
- 별도 곡 목록·색인은 단독 `■`나 구분선 뒤에 둡니다.
- 가져온 뒤 미리보기에서 구조와 원문을 확인합니다.

## 자동으로 확정하지 않는 것

| 입력 | 주의할 점 |
|---|---|
| 날짜·URL·댓글 ID·자유문장의 숫자 | 모두 영상 시각으로 바꾸지 않음 |
| 괄호 안 시각 | 선두의 닫힌 시각 괄호는 이동 지점. 제목 뒤 참고 괄호의 이동·종료·정정 의미는 직접 확인 |
| 자유 제목·들여쓰기 | 구조 근거가 없으면 주제 구간으로 만들지 않음 |
| 판 목록만 있는 입력 | 판이 여럿이어도 별도 제목·목록 근거 없이 부모나 명단을 만들지 않음 |
| 갈드컵·티어표의 VS 이름 | 실제 합방·참석자로 추측하지 않음. 명시 with·합방 선언은 별도로 보존 |
| 인물 이름 | 후보 방송인이 맞는지 확인. 방송 시간대 겹침은 참석·영상 0초·같은 장면·정렬의 확정이 아님. 어긋난 장면은 시각 보정 |

번호 목록만으로 목차 깊이를 만들지 않습니다. 완전한 선두 시각·닫힌 강조·시각 괄호·콜론 등 [지원하는 변형](existing.md#괄호-번호-콜론도-읽습니다)을 읽되, 전각 숫자, 임의 분류, 복잡한 Markdown·HTML의 모든 변형은 지원하지 않습니다. 댓글 자동 게시, 답글 전체 자동 수집, 이미 채택한 자료의 자동 변경도 하지 않습니다.

## 구조와 명단의 경계를 확인하세요

- **명단 앞뒤:** 빈 줄은 허용하지만 일반 설명·구분선·손상 시각·다른 원래 댓글을 넘어 붙이지 않습니다. 앞뒤가 각각 독립 합방이면 소속을 확정하지 않습니다.
- **같은 시각:** 같은 합방의 중복 판은 point로 보존할 수 있습니다. 기존 명시 d1과 새 시간 없는 제목의 첫 판이 같은 시각이면 기존 역할을 덮지 않고 소속 확인을 남깁니다. 독립 목차나 역순 시각까지 같은 그룹으로 고치지 않습니다.
- **새 명단:** 한 판의 직접 명단·없음·미확인은 그 판에서 이전 후보보다 우선합니다. 다른 판이나 새 합방에 임의로 전파하지 않습니다.
- **시각 없는 장벽:** 추론한 합방 중간의 독립 설명·비교·종료는 뒤 장면과 연결을 끊습니다. 종료 시각을 모르면 뒤의 음악·저챗 시각이나 영상 끝으로 채우지 않습니다.
- **일부 본문·손상 경계:** **일부만 가져옴 · 끝 미확정**을 확인하세요. 불명확한 끝을 전체 VOD 참석 기간으로 늘리지 않습니다. 확인 가능한 앞 구간과 명시 범위는 유지합니다.

검색 후보가 보인다는 것은 확인할 이름이 있다는 뜻입니다. 이름·후보 조회 범위·방송 시간대 겹침이 실제 참석·같은 장면·정렬을 확정하지 않습니다. [실제 입력과 결과](existing.md#기호-없는-제목과-판-목록) · [명단 후보와 VS](people.md#합방-시작-앞뒤의-명단과-팀-표기) · [장면 끝과 후보 조회 끝](timeline.md#장면의-끝과-합방-후보-조회의-끝)

## 원본 영상 복사를 선택했을 때

편집자용의 개발 중인 **원본 유지**는 일반판과 별도 수락 대상입니다. 현재 개발 설치의 새 Export/Quick Export 요청은 가능한 원본 영상 복사를 우선하며, 저장된 꺼짐 선택·명시한 압축 설정과 Quick 프리셋의 처리 의도는 유지합니다. 같은 편집 결과를 유지할 수 있는 영상만 복사합니다. 소리는 기본적으로 AAC로 처리하며, 조건이 맞는 원본 소리를 다시 압축하지 않는 경로도 현재 개발 설치에 포함되어 있습니다. 원본 유지 중 대기열 추가는 지원하지 않습니다. 실제 완성 파일·소리·오류 뒤 재시도 검증이 남아 있으며, 자동 검사나 일반판 파일의 성공만으로 이 후보의 저장·소리·Studio 전달이 확인된 것은 아닙니다.

현재 편집자용 개발 설치의 원본 소리 복사는 다음 범위에서 조건을 검사합니다. 길이가 확정되고 암호화되지 않은 일반 MP4의 AAC-LC 스테레오 소리 전체 중, 원래 시작·끝과 재생에 필요한 정보를 보존할 수 있는 경우만 검토 대상입니다. 조각형 MP4, 일부 소리 구간과 확인할 수 없는 정보는 이 복사 대상에 포함하지 않습니다. 설치·재로드 뒤 오류 차단과 기존 작업·첨부 자료 보존은 확인했지만, 이 경로의 실제 완성 파일 정상 재생·청감·입모양 동기와 Studio 전달은 아직 미확인입니다. 추가 원본 지원을 위한 후속 수정은 소스 검토·자동 검사까지 확인했으며 설치본 반영과 실제 출력 확인은 별도로 남아 있습니다. 영상 재처리가 필요한 출력도 정확한 구간과 파일 완료를 함께 확인하기 전에는 원본 소리가 안전하게 전달됐다고 판단하지 않습니다. 원본 소리 복사의 완료 증거가 없거나 서로 맞지 않으면 추가 재묶기 대신 전달을 중단하고 기존 편집 내용을 보존합니다.

편집자용 로컬 직접 저장은 단일 H.264 MP4·별도 자막 없는 출력에서 실제 OS 저장창으로 위치와 이름을 고른 뒤 영상 생성과 파일 쓰기를 함께 진행합니다. 마지막 파일 닫기와 크기 확인이 끝나야 완료입니다. 다른 형식은 브라우저 다운로드 설정을 따릅니다. 코드 검사·빌드, 각 실제 파일의 저장·재생, 오류 뒤 명시 재시도는 별도로 확인합니다. 저장 응답이 불분명하거나 오류·취소가 표시되면 실제 파일을 완성본으로 사용하지 마세요. 기존 원본을 보존하려면 새 이름으로 저장하세요.

일반판과 편집자판 **CVA-TTaempad pro**는 **Studio 탭 전달 / 빠른 전송(Google 계정)**을 구분합니다. Studio는 로그인된 업로드 탭을 선택해 채널을 확인하며 Pro에서는 채널 주소도 입력할 수 있습니다. 빠른 전송은 Studio 주소 없이 **로그인 / 계정 선택 / 로그아웃 / 상태 확인**과 **업로드할 YouTube 채널**을 사용합니다. Google 계정과 YouTube 채널 선택은 Studio 탭 선택과 별개입니다. [각 버튼의 차이](cuts.md#google-계정-연결과-studio-탭-선택)를 확인하세요. 현재 개발 설치의 일반판·Pro에서 Google 공식 창으로 바로 연결하고 같은 작업실에 선택 채널이 표시되는 흐름을 확인했습니다. Pro에서는 전송 취소 뒤 로그아웃·재로그인과 새 비공개 업로드 완료도 확인했습니다. 채널이 없거나 여러 개이면 임의로 확정하지 않습니다. 권한 만료·백그라운드 재시작 뒤에는 명시적으로 다시 로그인하며 자동 갱신·기본 계정 대체·수신 불명 영상 자동 재전송을 하지 않습니다. 모든 영상은 기본 비공개입니다. 생성과 전송이 겹쳐 대기 시간을 줄일 수 있지만 환경에 따라 속도는 달라집니다. Google 데이터 접근 검증은 아직 **NOT_SUBMITTED**이며 공개 페이지·브랜딩 확인과 OAuth 승인은 별개입니다. 연결을 마치지 못하면 Studio 탭 전달이나 파일 저장을 사용할 수 있습니다. **ⓘ 안내**는 출력 중에도 읽을 수 있으며 [개인정보 처리방침](https://ttaempad.arai.kr/privacy)에서 권한과 데이터 전송 내용을 확인할 수 있습니다. [최근 출력 확인 범위](#최근-개발-출력의-확인-범위)와 전체 출시 완료는 별개입니다.

일반판과 편집자용 후속 개발 설치를 같은 Chrome에서 검사한 720p 다시보기 한 사례에서는, 소리가 영상보다 늦게 끝나는 구간의 끝 직전으로 바로 이동해도 정밀한 시각이 유지되고 정지 화면이 정상 재생의 마지막 화면과 일치했습니다. 다른 다시보기·화질, 완성 출력 파일과 소리 품질은 별도로 검증 중이며, 이 확인은 전체 1.0 수락을 뜻하지 않습니다.

## 최근 개발 출력의 확인 범위

일반판의 한6분 구간은 원본 우선을 켰어도 컷 끝의 복사 조건이 맞지 않아 영상·소리를 다시 생성했습니다. 파일 저장과 전체 디코딩은 확인했지만, 시작 부분이 원본의 영상·소리와 정확히 맞는지, 듣기에 자연스럽고 입모양과 소리가 맞는지는 검증 중입니다. 이 사례가 다른 입력의 원본 복사나 완전한 영상·음성 보존을 보장하지는 않습니다. 처리 효율 개선의 실제 속도도 별도로 확인하고 있습니다.

### 편집자용 원본 소리 복사의 현재 확인 범위

작은 합성 원본을 사용한 편집자용 개발 검증에서는1.98초 출력의 원본 AAC 데이터·설정·복구 정보가 그대로 유지됐습니다. 당시 같은 디코더로 푼 원본과 복사 결과의 소리 값도 일치했습니다. 당시 검사기에서는 파일에 지정한 재생 범위보다192샘플이 더 나왔고, 이후 버전으로 같은 두 파일을 검사했을 때는 모두 지정한 재생 범위에 맞게 끝났습니다. 파일을 자동으로 잘라 맞추거나 실제 청감·전체 입모양 동기를 통과한 것으로 처리하지 않았습니다. 다른 장치·코덱·긴 영상과 실제 Studio 전달은 별도 검증이 필요합니다.

파일에 지정된1.98초를 읽도록 검사기를 수리하고 자동 검증과 개발 설치 폴더 반영을 마쳤습니다. Chrome 연결 도구가 응답하지 않아 확장 재로드와 실제 화면 반영은 미검증입니다.

일부 구간을 다시 압축한 대조에서는 일반 로컬 저장 파일이 선택한 끝보다 길게 선언되는 문제와, Studio용 변환 뒤 영상 시각이 한 프레임 밀리는 문제가 각각 확인됐습니다. 소스 수리와 별도 합성 파일의 끝 검사는 마쳤으며, 실제 Chrome에서 최종 파일의 재생 수락은 남아 있습니다. 원본 소리 복사 성공과 다시 압축한 소리의 최종 길이·품질은 각각 확인합니다.
