# 작성 기준

**시각을 쓰고, 설명을 붙이고, 미리보기에서 확인하세요.** 다음 기준만 알아두면 시작할 수 있습니다.

## 시각은 영상 시작부터

| 표기 | 뜻 |
|---|---|
| `02:35` | 2분 35초 |
| `1:02:35` | 1시간 2분 35초 |
| `60:00` | 60분, 즉 1시간 |

초는 **00–59**로 씁니다. `H:MM:SS`의 분도 00–59입니다. 날짜나 실제 시계의 시각은 영상 시각과 다릅니다.

## 순간과 구간을 구분하세요

```text
- 02:35 다시 볼 순간
- 03:00 ~ 04:00 [M] 설명을 함께 보기
- 04:10 ~ 04:30 [H] 결정적인 장면
```

- **시각 하나:** 이동할 순간입니다. 다음 시각까지의 구간을 만들지 않습니다.
- **시작과 끝:** 시작보다 끝이 뒤여야 합니다.
- **별·BEST:** 작성자가 강조한 순간입니다. 컷으로 담을지는 직접 결정합니다.

[구간과 강조의 화면 예제](ranges.md)

## 주제 아래에 장면을 두세요

```text
# 00:00 ~ 20:00 첫 게임
## 01:00 ~ 10:00 첫 판
- 02:35 사건
## 10:00 ~ 18:00 두 번째 판
```

**d1은 큰 주제, d2는 그 안의 장면, point는 순간**입니다. 더 깊은 제목은 바로 위 단계 아래에 둡니다. 제목은 `#`부터 `######`까지 쓸 수 있습니다.

제목에 시작만 적으면 다음 제목이나 부모 구간·영상의 끝을 기준으로 끝을 계산합니다. 댓글이 잘렸거나 경계를 알 수 없으면 **끝 미확정**으로 남습니다. 직접 적은 끝은 유지합니다.

[d1·d2·point 읽는 법](timeline.md) · [기존 목록과 들여쓰기](existing.md)

## 괄호와 별도 목록을 확인하세요

| 예 | 읽는 방법 |
|---|---|
| `01:23 시작 (02:55)` | 앞 시각 01:23로 이동. 괄호의 뜻은 직접 확인 |
| `01:23 / 02:55 시작` | 두 순간 |
| `01:23 ~ 02:55 [메모] 시작 구간` | 하나의 범위 |
| 단독 `■` 또는 구분선 | 앞 이야기와 구분된 새 목록 |

선두의 `[01:00] 제목`, `(01:00) 제목`, `【01:00】 제목`은 이동 지점으로 읽습니다. 번호나 시각 뒤 콜론도 사용할 수 있습니다. 제목 뒤 괄호 시각이 실제 시작·정정·참고 중 무엇인지는 자동으로 정하지 않습니다.

## 이름으로 비교 영상 찾기

맨 위에 `합방 : 이름 A, 이름 B`만 적으면 문서 전체의 비교 조회 명단입니다. 특정 구간의 참석 명단은 제목 아래 `합방:`으로, 장면의 관련 인물 단서는 `(w. 이름)`으로 적으세요. 같은 별칭을 서로 다른 사람에게 연결하지 않습니다.

기본 현재 명단은 구간에 적힌 순서, 전체 멤버는 첫 등장 순서입니다. 원본을 제외한 처음 12명을 불러오고 **더보기**마다 다음 12명을 이어 조회합니다. 공개 링크가 없어도 채택·복원한 댓글 명단으로 찾을 수 있습니다. 기존 명시 VOD와 수동 선택을 보존하며, 분할 VOD는 같은 검증 채널 한 행에 시간순으로 표시합니다. 방송 시간대 겹침과 실제 같은 장면·참석은 구분하세요.

목록에서 이름을 눌러 비교 영상을 여세요. 이름이 모호하거나 후보 신원이 미확인이면 직접 확인·선택합니다. 빈 구간을 누르면 원본만 이동합니다. 일부 조회·접근 제한은 자동으로 해결했다고 판단하지 않습니다. 같은 장면이 어긋나면 **시각 보정**을 사용합니다. [인물과 합방 예제](people.md)

## 가져온 뒤 확인할 것

1. 실제 영상의 시각인지 확인합니다.
2. 주제·장면·순간이 의도대로 나뉘었는지 봅니다.
3. **끝 미확정**이나 오류 안내를 확인합니다.
4. 사용할 자료를 **시간축에 불러오기**로 적용합니다.

파일 선택과 미리보기만으로 기존 자료가 바뀌지 않습니다. [파일 가져오기](summary.md) · [문제 해결](limits.md)
